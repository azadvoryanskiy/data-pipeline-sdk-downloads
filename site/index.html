How it works

1 · EXTRACTGitHub Actions, 07:00 UTCFetches the last 14 days from both APIs, with pauses and retries for rate limits.
2 · LANDOne CSV per source per dayCommitted to the repo. Re-running overwrites the same days, so it is safe to repeat.
3 · MODELdbt on DuckDBStaging, then a model that flags missing days and dropouts, then the marts.
4 · TESTdbt testsUniqueness, gaps, unknown packages, freshness. A failure stops the deploy.
5 · PUBLISHThis pageReads one JSON file exported from the marts and goes up on GitHub Pages.
